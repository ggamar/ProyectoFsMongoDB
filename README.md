## ✨ Características

- Servidor backend dinámico construido sobre Node.js y Express.
- Persistencia de datos mediante MongoDB y ODM (Mongoose).
- Interfaz de usuario interactiva desarrollada en el frontend.
- Separación clara de responsabilidades entre cliente y servidor.
